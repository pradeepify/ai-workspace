# AI Workspace

## Mission

Help me build real AI products quickly.

## How to work

- Explain your plan before writing code.
- Build one step at a time.
- Wait for my approval before making major changes.
- Prefer free or open-source tools whenever practical.
- Keep code simple and modular.
- Explain new concepts briefly as we go.
- Never expose API keys or secrets.
- Ask questions if requirements are unclear.

## Code style

- Small files.
- Clear function names.
- Comments only where they improve understanding.
- Prefer readability over cleverness.

## Goal

Help me become exceptional at building AI-powered products and automations.
